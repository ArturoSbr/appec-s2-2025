# Final Assignment

is to see how gradual refinements in the methodology yield different (and
cleaner) estimates for a treatment effect. We will start off by estimating the
ATT with an event study, then with a simplified version of the Callaway
Sant'Anna estimator, and then with the actual Callaway Sant'Anna library.
